**Director:** Jeanne Bliss (CPO / Customer Experience)
**Date:** 2026-03-04
**Focus:** Player retention in drop-merge, UX of Yandex Games top casual titles, audience reconciliation

## Kill Question Answer

**"Что потеряет пользователь, если мы исчезнем завтра?"**

Честный ответ: почти ничего. На Яндекс Играх сотни клонов drop-merge и merge-игр. Если мы не создадим специфическую причину возвращаться — игрок переключится за 10 секунд.

**Что создаёт ненулевой ответ:**
- Таблица рекордов (личный счёт — человек хочет побить своё)
- Визуальный прогресс (я вижу, как мои объекты становятся больше)
- Момент "слияния" — тактильное удовольствие, которое вызывает нейрохимическую реакцию (дофамин от каждого merge)
- Знакомые, привязанные к культуре объекты (тематика, которая говорит "это для меня")

**Вердикт:** Пока слабый. Drop-merge механика сама по себе — не моат. Моат строится через: правильную тематику (визуальный стиль), мгновенный "wow moment" при первом слиянии, и таблицу рекордов, которая создаёт петлю возврата. Без этого — продукт невидим.

## Focus Area 1: PMF Signals — Что удерживает игроков в drop-merge

### Findings

**Механика дофаминового цикла drop-merge работает универсально:**
- Физика падения + звук слияния + визуальный эффект роста объекта = трёхкратный дофаминовый триггер
- Gold & Goblins (merge + idle) достиг **56% D1 retention** при запуске — эталон для жанра в мобильных казуалках (источник: PocketGamer, сентябрь 2025)
- Merge-жанр показал рост вовлечённости на **34% год к году** в 2023-2024 (источник: Digittrix, апрель 2025)
- Казуальные игры составляют **78% всех загрузок** мобильных игр глобально

**Benchmarks для нашей платформы (браузер/HTML5, Yandex Games):**
- Браузерные казуалки имеют более низкий retention чем мобильные (~60-70% от мобильных показателей)
- Ориентиры для puzzle/casual жанра в mobile: D1 ~40-50%, D7 ~20-25%, D30 ~8-12%
- Для browser-based (Yandex Games): реалистично D1 ~25-35%, D7 ~10-15%
- NPS для казуальных puzzle игр: 20-40 (умеренный), топы достигают 60+

**Три главных механики retention в drop-merge:**

| Механика | Как работает | Пример |
|----------|-------------|--------|
| Прогрессия объектов | Игрок видит "следующий уровень" — вишня → апельсин → дыня | Suika Game (8 уровней фруктов) |
| Highscore loop | Личный рекорд — встроенный мотив вернуться | Любой аркадный жанр |
| "One more try" | Game over = немедленное желание переиграть | Тетрис-эффект, подтверждён у Suika Game |

**Что НЕ работает для retention (anti-patterns):**
- Принудительная реклама в первые 60 секунд → немедленный отток
- Слишком сложный туториал → 30-40% бросают до первого слияния (источник: Anton Slashcev, LinkedIn 2025)
- Отсутствие звука при слиянии → потеря ключевого дофаминового триггера

### Risk

PMF для нашего конкретного проекта пока не проверен. Мы копируем проверенную механику, но не знаем, выберет ли аудитория Яндекс Игр именно нашу реализацию. На платформе уже есть merge-игры (жанр #2 по росту).

### Opportunity

Drop-merge (Suika-тип) — специфическая ниша внутри merge-жанра, физически отличная от idle-merge. На Яндекс Играх этот подвид может быть недопредставлен относительно интереса аудитории. Если браузерные реализации плохого качества — мы можем взять планку качества.

## Focus Area 2: UX-анализ конкурентов

### Findings

**Топ казуальных игр Яндекс Играх (данные из каталога, март 2026):**

| Название | Рейтинг | Жанр | Что работает |
|----------|---------|------|-------------|
| По полочкам: Сортировка предметов | 90 | Сортировка | Чёткий прогресс, знакомые предметы |
| Пакринг Кар | 91 | Паркинг-пазл | Один тап — одно действие, понятный goal |
| Block Blast 2048 | 95 | Блоки+2048 | Знакомая механика в новой обёртке |
| Ball Sort Puzzle | 85 | Сортировка цветов | Релаксирующий, без тайм-пресса |
| Block Puzzle Adventure | 84 | Блоки | Прогресс через уровни, сессии 2-3 мин |

**Что объединяет топ-игры на Яндекс Играх:**
1. **Один тап — одно действие** — никаких жестов, никакого свайпа, только клик/тап
2. **Визуальная чистота** — нет лишних элементов интерфейса при первом запуске
3. **Немедленный feedback** — каждое действие имеет видимый результат
4. **Знакомые объекты** — предметы, которые игрок узнаёт (карточки, блоки, шары)
5. **Отсутствие туториала в виде текста** — обучение через действие

**Анализ Suika Game клонов на браузерных платформах:**
- Momo Games (Watermelon Suika Game на GameDistribution) набрал **1.1M plays** — доказывает спрос в браузере
- Разработан одним человеком за короткий срок с помощью AI-инструментов (прямой аналог нашего кейса)
- Ключ к успеху по словам разработчика: обновления контента и событийные версии продлили жизнь игры

**Где конкуренты проваливаются (из отзывов игроков 50+, AARP Survey 2023):**
- 69% геймеров 50+ чувствуют, что игры сделаны без учёта их потребностей
- Главные жалобы: агрессивная реклама, непонятные туториалы, слишком мелкие элементы UI
- Принудительная реклама особенно раздражает эту аудиторию

**Cozy Merge (Steam, 2024):**
- 96% положительных отзывов (156 reviews)
- Ключ: атмосфера (камин, снег, спокойная музыка) + привычная механика merge конфет
- Доказывает: тематика "уют" + merge = работает для взрослой аудитории

### Our Opportunity

1. **Качество звука и анимации слияния** — большинство клонов экономят на этом, а именно здесь главный дофаминовый триггер
2. **Крупные элементы UI** — специально под аудиторию 55+
3. **Мягкая реклама** — показывать interstitial только после game over, не раньше
4. **Атмосфера "уюта"** — Cozy Merge показал, что это работает

## Focus Area 3: User Pain Points и Jobs-to-be-Done

### Jobs-to-be-Done (кого нанимают нашу игру)

**Первичная аудитория Яндекс Игр (58% женщины, 38% — 55+):**

Эта аудитория нанимает казуальную игру для одного из трёх:
1. **"Убить 5 минут"** — пауза, очередь, реклама в телевизоре (сессионность)
2. **"Дать мозгу отдохнуть"** — релаксация без социального давления
3. **"Почувствовать прогресс"** — видимое достижение за короткую сессию

**Камиль (10 лет, сын основателя):**
- Нанимает игру за: физическую механику, визуальное удовольствие, соревновательность
- Хочет: быстрое action-feedback, рекорды, "крутой визуал"

**Текущие workarounds аудитории:**
- Играют в Bubble Shooter, Match-3, Solitaire — жанры-дефолт для этой демографии
- Crossword/Word games занимают значительную долю времени (россиянки 36+ по данным Yota 2024)

**Время/деньги на workarounds:**
- 50-plus геймеры тратят в среднем 12 часов/неделю на игры (рост 40% с 2019, AARP 2023)
- Готовы платить $49 за 6 месяцев на игровой контент

### Current Workarounds (как решают задачу сегодня)

| Аудитория | Что играют сейчас | Зачем |
|-----------|-------------------|-------|
| Женщины 55+ | Match-3 (Royal Match, Lily's Garden) | Релаксация + нарратив |
| Женщины 35-55 | Сортировки ("По полочкам"), Ball Sort | Чистый пазл без историй |
| Дети 10-15 | Аркады, раннеры, IO-игры | Экшен, скорость |

**Ключевой инсайт:** Drop-merge не является привычным жанром для аудитории 55+. Это возможность (новинка) и риск (непривычность) одновременно.

## Focus Area 4: Retention Patterns

### Industry Benchmarks

| Метрика | Hyper-casual | Casual puzzle | Merge (mobile) | Наш ориентир (browser) |
|---------|-------------|---------------|----------------|----------------------|
| D1 retention | 30-35% | 40-50% | 45-56% | 25-35% |
| D7 retention | 10-15% | 20-25% | 20-30% | 8-15% |
| D30 retention | 3-5% | 8-12% | 10-15% | 4-8% |
| Целевой NPS | — | 20-40 | 30-50 | 20-35 |

Источники: GameAnalytics, Reddit /r/unity (2025), PocketGamer Gold & Goblins case (2025), Appodeal Benchmarks 2025

**Важно для Яндекс Игр:**
- Рейтинг < 30 за 3 недели = автоудаление платформой
- Рейтинг формируется из DAU, retention, playtime, пользовательского рейтинга
- Значит: **D7 retention критически важен для выживания на платформе**

### Churn Triggers — когда и почему игрок уходит

| Триггер | Когда | Что делать |
|---------|-------|-----------|
| Первая реклама слишком рано | Первые 30-60 сек | Реклама только после game over |
| Game over без "ещё раз" | После любого проигрыша | Prominent "Play Again" кнопка |
| Непонятно что делать | Первые 10 секунд | Implicit tutorial (стрелка + drop) |
| Скучно после 3 партий | D1-D2 | Прогрессия объектов (новые уровни) |
| Нет причины вернуться завтра | D3 | Highscore + personal best badge |

**Ключевой retention-момент для нашей аудитории 55+:**
- Они НЕ терпят агрессивную рекламу (AARP: это #1 причина удаления)
- Они ценят ощущение достижения без сложности
- Они возвращаются из-за привычки, не из-за FOMO

## Focus Area 5: Switching Costs

### Lock-in Mechanisms

**Что создаёт стикинесс в drop-merge:**

| Механизм | Описание | Сложность внедрения |
|----------|---------|---------------------|
| Personal highscore | "Мой рекорд — 1247, хочу 1500" | Низкая |
| Yandex leaderboard | SDK поддерживает таблицы лидеров | Средняя |
| Прогрессия объектов | Игрок ещё не видел финальный объект (арбуз) | Встроено в механику |
| Визуальная память | "Я помню этот уровень сложности" | Встроено |

**Что НЕ создаёт lock-in в нашем случае:**
- Нет социального графа (нет "друзья играют")
- Нет контента, который накапливается (нет прогрессии персонажа)
- Нет ежедневных наград (не планируем добавлять — scope creep)

### Risk Assessment

**Switching cost = НИЗКИЙ.** Любой клон drop-merge заменит нашу игру мгновенно. Единственный реальный lock-in — личный рекорд и эмоциональная привязка к "своей" версии механики.

**Митигация:** Сделать первые 30 секунд настолько приятными, что игрок сформирует ассоциацию с нашей конкретной реализацией. Звук, анимация, тематика — всё это создаёт эмоциональный fingerprint.

## OQ-2: Решение вопроса — Целевая аудитория

### Противоречие

"Камиль (10 лет) нравится" vs "платформа: 55+ женщины"

### Исследование показало

**Это противоречие — ложное при правильном визуальном стиле.**

Данные:
1. Drop-merge механика **универсально привлекательна** — физика + слияние работают на оба сегмента
2. Ключевой разделитель — **тематика/визуальный стиль**, а не механика
3. "Cozy" стиль (Cozy Merge, Lily's Garden) = **работает для 35-65 женщин**, но не отталкивает детей
4. Животные (Capy Merge, Drop the Cat) = **работает для всех возрастов** — нейтральная тема

**Стратегия "двойной аудитории":**

Gossip Harbor (merge + story) стал лидером жанра в США именно благодаря **визуальной стилистике, привлекательной для женской аудитории**. Механика та же что у конкурентов, но тематика сделала игру "своей" для конкретной аудитории.

### Решение OQ-2

**Первичная аудитория: женщины 35-65 (демография платформы)**
**Вторичная аудитория: дети и подростки (более низкий porог входа)**

Это не компромисс — это правильная приоритизация. Делать игру "для демографии платформы" = делать игру, которая получит трафик от алгоритма Яндекс Игр. Камиль всё равно сможет играть и гордиться — механика не меняется, только тематика.

**Конкретно:**
- Первичный тест: покажи мамам/бабушкам 35-65. Нравится? Хорошо.
- Если "Камилю не нравится иконка" — это нормально. Он не целевой пользователь.
- Камиль = учебный эксперимент, игроки = аудитория платформы.

## OQ-5: Решение вопроса — Визуальный стиль

### Исследование показало

**Стили по эффективности для аудитории Яндекс Игр:**

| Стиль | Аудитория | Retention | Примеры | Оценка |
|-------|-----------|-----------|---------|--------|
| Животные (cute) | Все возрасты | Высокий | Drop the Cat, Capy Merge | ★★★★★ |
| Уют/Cozy | Женщины 35+ | Высокий | Cozy Merge (96% positive) | ★★★★★ |
| Фрукты (Suika) | Все | Средний | Уже много клонов | ★★★ |
| Геометрия/минимал | Молодые | Средний | Работает, но нет "wow" | ★★★ |
| Свой сеттинг (фэнтези) | Гейм-культура | Низкий | Слишком сложно за неделю | ★★ |

**Ключевые находки:**
- Жанр merge с "cute animals" — доминирующий визуальный паттерн (Capy Merge, Drop the Cat, Merge Dragons)
- Аудитория 55+ женщин особенно реагирует на: милые животные, тёплые цвета, отсутствие агрессии
- Русскоязычная аудитория: нет специфических культурных ограничений, animal-тематика универсальна
- Фрукты (Suika) = уже насыщен конкурентами, нет дифференциации
- Геометрия = слишком холодная для женской аудитории 55+

### Решение OQ-5

**Визуальный стиль: МИЛЫЕ ЖИВОТНЫЕ (Cute Animals)**

**Конкретная рекомендация:**

Взять механику drop-merge, но заменить фрукты на **набор из 8-10 милых животных**, которые "эволюционируют" при слиянии:

```
Хомяк → Кролик → Котёнок → Кот → Пёс → Лиса → Панда → Медведь (финал)
```

**Почему это лучше фруктов:**
1. Дифференциация от Suika-клонов (не ещё один фруктовый merge)
2. Идеально для аудитории 55+ женщин (животные = эмоциональная привязка)
3. Не отталкивает Камиля и детей (cute animals универсальны)
4. Не требует больше ассетов — те же 8-10 спрайтов
5. Название игры становится уникальным: "Зверята" / "Пушистые" / "Animal Merge"

**Реализация за неделю:**
- Бесплатные иллюстрации: OpenGameArt.org, Kenney.nl (animal sprites, CC0)
- ИИ-генерация: Midjourney/DALL-E для дополнительных вариантов
- 8 спрайтов животных + 1 фон = весь необходимый визуал

## Recommendations

### Must-Have (критично для retention)

1. **"Wow moment" в первые 5 секунд** — первые два одинаковых объекта должны слиться с хорошим звуком и анимацией ДО любой рекламы. Это формирует эмоциональный fingerprint игры.

2. **Highscore + "New Record!" момент** — без этого нет причины возвращаться. Personal best = простейший retention-крючок.

3. **Game Over экран с "Ещё раз"** — prominent, мгновенный, без навязчивой анимации. Пользователь нажимает "ещё раз" на рефлексе.

4. **Крупные элементы UI** — кнопки минимум 44px (touch target), текст минимум 18px. Аудитория 55+ с телефоном читает плохо.

5. **Мягкая реклама** — только после game over, только interstitial, не banner в игровом процессе. Это не жертва монетизацией — это инвестиция в retention.

6. **Визуальная прогрессия** — игрок ВСЕГДА видит "следующий уровень" животного. Иконка следующего уровня = постоянный мотив продолжать.

### Avoid (anti-patterns, убивают retention)

1. **Реклама в первые 60 секунд** — гарантированный отток аудитории 55+. AARP подтверждает это как главную причину удаления.

2. **Текстовый туториал** — никто не читает. Только implicit: показать стрелку на первый объект, пусть игрок сам дропнет.

3. **Фруктовая тематика (Suika-клон)** — потеря дифференциации. Платформа уже видела сотни таких игр. Животные = выделяемся.

4. **Принудительный Game Over экран с паузой** — каждая дополнительная секунда между game over и "ещё раз" увеличивает вероятность закрытия вкладки.

5. **Слишком маленький контейнер** — фрустрация = отток. Для браузера контейнер должен быть визуально просторным.

## Audience Reconciliation: Камиль vs 55+ женщины

**Итоговая позиция CPO:**

| Измерение | Камиль (10 лет) | Женщины 55+ |
|-----------|-----------------|-------------|
| Механика | Нравится физика, скорость | Нравится логика, без давления времени |
| Визуал | Любой "cute" работает | Cute animals = идеально |
| Сессия | 5-15 мин | 3-7 мин |
| Реклама | Терпит rewarded | Не терпит принудительную |
| Мотив вернуться | Побить рекорд | Релаксация + рекорд |

**Overlap = 100% по механике, ~80% по визуалу, расхождение только в толерантности к рекламе.**

Делаем для **платформенной аудитории (55+ женщины)**. Камиль всё равно будет играть с гордостью — потому что создал. Но алгоритм Яндекса должен видеть игру, которая удерживает именно свою демографию.

## Kill Question Answer

**"Which ONE repeatable channel works right now?"**

**Ответ: Органический трафик из раздела "Новинки" Яндекс Игр.**

Это единственный бесплатный и предсказуемый канал для нового разработчика с нулевым бюджетом. Механика известна: первые ~7 дней после публикации игра автоматически попадает в раздел "Новинки" и получает показы от ML-алгоритма. Это единственное окно гарантированного трафика. После него — только органика из рейтинга.

CAC = $0 (платформа предоставляет трафик бесплатно).
Conversion rate из показа в сессию: зависит от иконки и обложки (benchmark CTR иконки в каталоге не публикуется Яндексом, но A/B-тест показывает разницу в кликабельности иконок).

Проблема: это одноразовый канал, не повторяемый. Для повторяемости нужно либо портфель игр (publish → "Новинки" → повторить), либо рост по ML-рейтингу. Для одной игры — это не PLG-воронка, это launch event.

## Focus Area 1: Как новые игры получают трафик на Яндекс Играх

### Официальные механизмы продвижения

Согласно официальной документации Яндекс Игр (yandex.com/dev/games/doc):

**1. Раздел "Новые" (New)**
- Новые игры автоматически попадают в отдельный раздел каталога
- Продолжительность нахождения: ~1 неделя (подтверждено несколькими разработчиками)
- Трафик в этот период — основной источник для новичков

**2. ML-ранжирование**
Алгоритм оценивает:
- Заполненность карточки игры (Card Completion Progress) — прямо влияет на ранжирование
- Рейтинг (публичный, рассчитывается автоматически)
- Количество игровых сессий
- Продолжительность сессии
- Количество возвращений (retention)
- Доход от рекламы

**3. Фичеринг (Featuring)**
- Включение в тематические подборки редакцией Яндекс Игр
- Требует Card Completion Progress = "зеленый" (100%)
- Недоступно новичкам без репутации — исключение

**4. Платное продвижение**
- Продвижение в каталоге и на страницах других игр
- Бюджет: нулевой — этот канал закрыт

**5. Реферальная программа**
- Партнерские ссылки через Яндекс Дистрибуцию
- Требует запуска рекламы в Яндекс Директ — бюджет нужен, закрыт

### Данные от реальных разработчиков

| Сценарий | Результат первой недели | Источник |
|----------|------------------------|----------|
| Простой кликер (мусорный клон) | 180 игроков, 17₽ | DTF, 2025 |
| Игра за 10-15 минут (простая механика) | 3,500 игроков, 1,204₽ | DTF, 2024 |
| Серьезная казуалка (Traffic Rider) | ~2,000₽ суммарно | DTF, 2024 |
| Качественная игра с хорошей карточкой | 50K-300K₽/мес | Платформа |

**Вывод по трафику:** Ключевая переменная — качество игры и карточки, а не маркетинг. Раздел "Новинки" = единственное окно. Всё, что происходит потом — зависит от retention метрик.

### Алгоритм рейтинга (критическое правило)

С августа 2024 года: если рейтинг игры <= 30 на протяжении 3+ недель — игра автоматически удаляется с платформы. Ранее порог составлял 100 дней.

Это означает: **первая неделя трафика из "Новинок" должна сразу генерировать достаточный рейтинг для выживания.**

## Focus Area 2: Оптимальные метаданные для CTR

### Card Completion Progress — что это и зачем

Яндекс Игры используют метрику "Card Completion Progress" (уровень заполненности карточки) как прямой фактор ранжирования:
- Красный = почти пусто, низкий приоритет
- Желтый = частично заполнено
- Зеленый = 100% заполнено, максимальный шанс в рейтинге

**Это не опциональная "красота", это фактор ранжирования ML-алгоритма.**

### Чек-лист карточки для максимального CTR

Согласно официальной документации + опыту разработчиков (DTF):

**Обязательные поля (влияют на модерацию):**
- [ ] Название игры (RU + EN)
- [ ] Описание (RU + EN)
- [ ] Иконка (размеры: 512x512 px минимум)
- [ ] Обложка/Cover
- [ ] Теги/категория жанра

**Для Card Completion Progress = зеленый:**
- [ ] Скриншоты (несколько)
- [ ] Видео-превью (геймплей)
- [ ] Локализация: минимум RU + EN, желательно + TR (турецкий)
- [ ] Поддерживаемые платформы (desktop + mobile)
- [ ] Жанровые теги

**Рекомендации по иконке (ключевой CTR-элемент):**
- Яндекс Игры встроили A/B-тест иконок прямо в консоль (50/50 split, результат через несколько дней)
- Иконка = первое что видит игрок в каталоге
- Best practice из mobile ASO (применимо здесь): яркий контрастный фон, крупный центральный объект, минимум текста
- Для merge/drop-механики: показываем момент слияния или крупный "финальный" объект

### A/B-тест иконок (встроенный инструмент Яндекс Игр)

- Доступен только после публикации игры
- Протестируй 2 варианта иконки в первые дни
- Метрика: конверсия из каталога в запуск игры
- Значит: нужно иметь 2 готовых варианта иконки к релизу

## Focus Area 3: Называть по-русски или по-английски?

### Анализ реальных игр в топе каталога

Из наблюдения топа Яндекс Игр (casual-категория, 2026):
- "Tiles Match: release stress 3D" — English название
- "Bubble Pop! Puzzle Game Legend" — English
- "Anime Dress Up - Doll Dress Up" — English
- "Battle of Middle-earth" — English
- "Obby the Squid Jump Rope" — English
- "Рыбка ест Рыбку: Эволюция" — Русское (нишевый контент, животные)
- "Угадай, кто я?" — Русское (нонограм-пазл)

**Паттерн:** Топ занимают English-названия + English-описания. Русские названия работают для нишевых или культурно-специфичных игр.

### Официальная рекомендация Яндекс Игр

> "Добавьте локализацию: заполните черновик игры на русском и английском языке. Если возможно, добавьте черновик на турецком языке."

**Вывод по языку названия:**

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| Только русское | Близко аудитории 55+ женщины | Отрезает 40% международного трафика, не попасть в глобальный топ |
| Только английское | Глобальный охват, выглядит "профессионально" | Меньше близости с ядром аудитории |
| **Русское + английский перевод** | Максимальный охват | Нужно перевести оба дraftа |

**Рекомендация: два черновика.** Основное название — универсальное (русское), с отдельным английским черновиком. Яндекс Игры позволяют заполнить карточку для каждой локали отдельно.

### Как называть конкретно drop-merge игру?

Анализ вариантов названий для Suika/drop-merge механики:

| Тип названия | Примеры у конкурентов | CTR-потенциал |
|--------------|----------------------|---------------|
| Описательное (что делать) | "Merge & Drop", "Drop Merge" | Понятно, но скучно |
| Эмоциональное | "Blob Drop", "Emoji Dropper" | Выше — запоминается |
| Тематическое (сеттинг) | "Fruit Suika", "Watermelon Drop", "Merge Zoo" | Высокий — образ сразу понятен |
| С числами/геймплеем | "2048 Balls", "Drop & Merge The Numbers" | Средний — нишевый |

**Выигрышная формула:** `[Тема/Сеттинг] + [Механика-глагол]`

Примеры для нашего проекта:
- "Слияние Планет" / "Planet Merge" — космос, универсально
- "Фруктовый Обвал" / "Fruit Drop" — прямая отсылка к механике
- "Капибары: Слияние" / "Capybara Merge" — мем-сеттинг, вирусный потенциал

**Избегать:** клонировать "Suika Game" в названии — модерация отклоняет очевидные клоны по бренду.

## Focus Area 4: Стратегия запуска — первая неделя критична

### Воронка трафика для новой игры

```
Публикация
    ↓
Раздел "Новинки" (~7 дней бесплатного трафика)
    ↓
ML оценивает: рейтинг + сессии + retention + доход
    ↓
Если рейтинг > 30 → остаётся в каталоге
Если рейтинг ≤ 30 за 3 недели → УДАЛЕНИЕ
    ↓
Хороший retention → рост в ML-рейтинге → больше трафика → цикл
```

### Ключевые метрики первой недели

| Метрика | Критический порог | Что делать |
|---------|-------------------|------------|
| Рейтинг | > 30 за 3 недели | Обеспечить через retention |
| Сессия | Длинная (ориентир: 5+ мин) | Drop-merge механика идеальна |
| Возвраты | Хоть какие в первую неделю | Лидерборд помогает |
| Доход | Любой положительный | Правильно настроить SDK |

### Временная шкала запуска

```
День 0: Подать на модерацию (3-5 раб. дней)
День 3-5: Получить апрув
День 1 после публикации: Игра в "Новинках"
День 1-7: КРИТИЧЕСКАЯ ФАЗА — максимум качества и вовлечённости
День 7: Выход из "Новинок" → переход в органику
День 21: Первая проверка рейтинга алгоритмом на удаление
```

### Что делать в первую неделю (операционный план)

1. **До публикации:**
   - Card Completion Progress = 100% (зеленый)
   - Подготовить 2 варианта иконки для A/B-теста
   - Записать геймплей-видео для карточки
   - Заполнить оба черновика (RU + EN)
   - Добавить жанровые теги (merge, puzzle, casual)

2. **После публикации (день 1-3):**
   - Запустить A/B-тест иконок немедленно
   - Мониторить метрики в консоли ежедневно
   - Проверить что SDK показывает рекламу корректно

3. **Неделя 1-3:**
   - Фиксить любые баги по отзывам
   - Улучшать retention-механики (лидерборд, рекорды)
   - Отслеживать рейтинг — не дать упасть ниже 30

## Focus Area 5: PLG vs Sales-Led и конверсионная воронка

### ACV-анализ

- Монетизация: реклама (CPM-based, не subscription)
- ACV = N/A для рекламной модели
- Это freemium PLG: игрок "приходит сам" через каталог, доход — пассивный от рекламы

**Motion: Pure PLG (product sells itself)**
- CAC = $0 (платформа = дистрибуция)
- Revenue = DAU * сессий_в_день * RPM_рекламы
- Активация = когда игрок увидел первое слияние объектов ("Aha moment")

### Конверсионная воронка

```
Показ в каталоге "Новинки"
    ↓ [CTR иконки — benchmark неизвестен, но A/B-тест встроен]
Клик → Запуск игры
    ↓ [Activation: % запустивших → дошедших до первого слияния]
"Aha moment" (первое слияние с физикой и звуком)
    ↓ [Retention D1: % вернувшихся на следующий день]
Повторная сессия
    ↓ [Монетизация: interstitial после game over]
Доход
```

### Benchmark retention для casual-игр

| Метрика | Плохо | Средне | Хорошо |
|---------|-------|--------|--------|
| D1 Retention | < 20% | 20-35% | > 35% |
| D7 Retention | < 7% | 7-15% | > 15% |
| Avg. session length | < 3 мин | 3-7 мин | > 7 мин |
| Sessions/DAU/day | < 1.5 | 1.5-2.5 | > 2.5 |

Drop-merge механика естественно поддерживает сессии 5-15 минут (подтверждено по Suika Game) — это выше среднего.

### "Aha moment" для drop-merge

**Активация происходит:** в первые 30 секунд игры — момент первого слияния двух одинаковых объектов с физическим эффектом и звуком.

Это критически важно для онбординга:
- Нельзя затягивать обучение
- Первое слияние должно произойти в первые 10 дропов
- Визуальный и аудио-фидбек должны быть максимально сатисфачингными

## Целевая аудитория: решение OQ-2

**Противоречие:** 58% женщины 55+ vs эксперимент для 10-летнего мальчика.

**Ответ с позиции CMO:**

Делаем игру для **платформенной аудитории (55+ женщины)**, а не для Камиля. Почему:
1. Камиль — стейкхолдер эксперимента, не игрок
2. Аудитория платформы = трафик = доход
3. Drop-merge (Suika) **идеально попадает** в эту аудиторию: расслабляющий геймплей, нет агрессии, нет скорости реакции, простое управление одним пальцем

**Визуальный стиль должен говорить аудитории:**
- Мягкие цвета (не кислотный неон)
- Понятные, милые объекты (животные, фрукты, овощи, планеты)
- Не геометрия и не "игра для программистов"

**Рекомендация по сеттингу:** Фрукты (Suika-совместимо) или животные/котики — максимально широкий аппил для женской аудитории 55+. Планеты — нейтральный вариант, меньший аппил для этой демографии.

## Стратегия запуска — финальные рекомендации

### Приоритет #1: "Новинки" окно — использовать на 100%

**Это единственный бесплатный канал с предсказуемым трафиком.** Всё должно быть готово к этому моменту.

### Приоритет #2: Card Completion = зеленый ДО публикации

| Элемент | Приоритет | Почему |
|---------|-----------|--------|
| Иконка (2 варианта) | Критический | CTR в каталоге |
| Обложка/Cover | Критический | Отображается в фичеринге |
| Видео геймплея | Высокий | Card Completion Progress |
| Скриншоты (3+) | Высокий | Card Completion Progress |
| Описание RU | Критический | Модерация |
| Описание EN | Высокий | +40% международного трафика |
| Теги/жанр | Высокий | ML-ранжирование |
| Лидерборд (SDK) | Средний | Retention + фичеринг "Наш выбор" |

### Приоритет #3: Название по формуле

**Финальная формула названия:**
```
[Русское название]: [Тема] + [Действие] — 2-3 слова максимум
[English]: [Theme] + [Action verb]

Примеры:
- "Фруктопад" / "Fruit Drop"
- "Планеты: Слияние" / "Planet Merge"
- "Котослияние" / "Cat Merge"
```

**Запрещено:**
- Слово "Suika" в названии (бренд)
- Слово "Clone" или намёк на клон
- Более 5 слов в названии (плохо отображается в каталоге)

### Стратегия после первой недели

Если рейтинг > 30 и есть позитивная динамика:
1. Итерировать механики retention (новые объекты, события)
2. Использовать встроенный A/B-тест иконок
3. Рассмотреть вторую игру того же жанра для портфельной стратегии

Если рейтинг падает к 30:
1. Немедленно пофиксить критические проблемы UX
2. Добавить лидерборд (если не было)
3. Проверить частоту рекламы (слишком частая реклама = уходы)

## Чего НЕ делать (Anti-patterns)

| Anti-pattern | Почему опасно |
|--------------|---------------|
| Публиковать с неполной карточкой | Прямо снижает ранжирование ML |
| Делать мусорный клон "суйки" | 29,000 удалённых игр — именно так и происходит |
| Игнорировать мобильную адаптацию | Android = основной трафик платформы |
| Ставить рекламу слишком часто | Retention падает → рейтинг падает → удаление |
| Только русский черновик | Теряем 40% международного трафика |
| Копировать название бренда | Отказ на модерации |

## Сводка для Совета Директоров

**Главный вывод:** Яндекс Игры — не app store с SEO-поиском. Это ML-платформа. Нет ключевых слов, нет внешнего трафика, нет платных инструментов при нулевом бюджете. Есть только одна точка входа: раздел "Новинки" + качество игры.

**Три решения, которые определяют судьбу игры:**
1. Карточка = 100% заполненная до публикации (влияет на ML-ранжирование)
2. Иконка = A/B-тест с первого дня (влияет на CTR = первичный трафик)
3. Retention = лидерборд + залипательная механика (влияет на рейтинг > 30 = выживание)

**Название:** 2-3 слова по формуле [Тема] + [Действие], два черновика (RU + EN). Рекомендация: тема = фрукты или животные (максимальный аппил для целевой демографии 55+ женщины).

**Определение успеха (OQ-1):** С точки зрения канала — успех это когда рейтинг > 30 через 3 недели. Это означает что платформа "приняла" игру. Денежный успех — следствие, а не цель первой недели.

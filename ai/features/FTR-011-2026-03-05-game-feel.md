# Feature: [FTR-011] Game Feel & Feedback
**Status:** queued | **Priority:** P0 | **Date:** 2026-03-05

## Why
PMC/NIH: "frustration from confusion" — #1 причина оттока у 55+. Мотивационные сообщения повышают retention. Near-miss effect (Springer, 2016): "почти победил" вызывает непреодолимое желание повторить — сильнее полного проигрыша. Gentle failure (мягкий game over без наказания) + быстрый рестарт = длиннее сессии.

## Context
Depends on FTR-005 (GameOverScene). Currently: game-over screen shows "Ой, ляп!" with score. No motivational feedback during gameplay, no near-miss detection, no warm encouragement.

## Research Reference
- G3: Gentle Failure Loop (Score 3.00)
- G5: Near-Miss Effect (Score 2.65)

## Design

### Motivational Toasts (G15)

Random encouraging messages on good plays:

**Triggers:**
- Merge tier 4+ (cat or higher): "Ого!" / "Здорово!"
- Merge tier 6+ (fox or higher): "Вот это мердж!" / "Красота!"
- Merge tier 8 (bear — max): "МЕДВЕДЬ! Невероятно!"
- Chain reaction (2+ merges in combo): "Каскад!" / "Цепочка!"
- New personal best during game: "Новый рекорд!"

**Display:**
```
1. Text appears center-top, below score
2. Font: Marmelad, 28px, warm color (ochre/gold)
3. Tween: scale 0 → 1.2 → 1.0 (200ms), hold 600ms, fade out 300ms
4. Max 1 toast at a time (new replaces old)
```

**Messages array (random pick per trigger):**
```typescript
const TOASTS = {
  goodMerge: ['Ого!', 'Здорово!', 'Отлично!', 'Класс!'],
  greatMerge: ['Вот это мердж!', 'Красота!', 'Потрясающе!'],
  maxMerge: ['МЕДВЕДЬ!', 'Невероятно!', 'Легенда!'],
  combo: ['Каскад!', 'Цепочка!', 'Комбо!', 'Серия!'],
  newRecord: ['Новый рекорд!'],
};
```

### Near-Miss on Game Over (G5)

Track during gameplay:
- `highestTierCreated: number` — max tier achieved this session
- `closestMerge: { tierA: number, distance: number } | null` — closest pair that almost merged

**Game Over screen additions:**
```
If highestTier < 8:
  Show: "До {nextAnimalName} — совсем чуть-чуть!"
  With silhouette of next tier animal

If score > best * 0.8 && score < best:
  Show: "Почти побили рекорд! Не хватило {diff} очков"

If score > best (new record):
  Show: "🏆 Новый рекорд!" with celebration animation
```

### Warm Game Over Redesign (G3)

Current: "Ой, ляп!" — fine, keep it.

Additions:
- Show session stats: "Мерджей: {count}" / "Лучший мишка: {tierName}"
- Randomized warm closing message: "Отличная игра!", "Так держать!", "Вы молодец!"
- "Ещё разок" button more prominent (larger, pulsing glow)
- Show "Рекорд побит!" banner if new record

### Data Tracking

In GameScene, track per-session:
```typescript
private sessionStats = {
  mergeCount: 0,
  highestTier: 1,
  isNewRecord: false,
};
```

Pass to GameOverScene via scene data.

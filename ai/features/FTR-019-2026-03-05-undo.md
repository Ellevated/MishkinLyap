# Feature: [FTR-019] Undo / Save-Me
**Status:** queued | **Priority:** P0 | **Date:** 2026-03-05

## Why
Undo/Save-Me (Score 2.60): одна бесплатная отмена дропа за игру. Снижает фрустрацию для ЦА 55+ — "ой, не туда кинула". Rewarded ad за дополнительный undo — высочайшая конверсия (эмоциональный момент). Candy Crush pattern: undo как "последний шанс" формирует привязанность.

## Context
Depends on FTR-005 (GameScene), FTR-003 (Animal). Currently: after drop, animal is committed — no way to take it back. `AnimalSpawner.spawnAtDrop()` creates animal and emits `ANIMAL_DROPPED` event.

**Technical research finding:** Full Matter.js physics snapshot/restore НЕ работает надёжно (GitHub issue #143). Solver хранит внутренние islands и contact pairs — они не сериализуются. **Единственный рабочий подход: destroy последнее dropped Animal в окне ~0.8s до первого контакта с другими телами.**

## Research Reference
- G11: Undo/Save-Me (Score 2.60)

## Verified Limitations
- Matter.js state snapshot: unreliable, не использовать
- Undo window: только до первого collision с другим animal
- Phaser Matter collision event: `this.matter.world.on('collisionstart', ...)`

---

## Scope
**In scope:** One free undo per game, undo button in UI, undo available only before last animal collides, visual feedback on undo
**Out of scope:** Multiple undos, rewarded ad for extra undo (Sprint 4), undo history (more than 1 level)

} as const;

### Undo State Tracking

In GameScene:
```typescript
private undosRemaining = 1;           // reset on create()
private lastDroppedAnimal: Animal | null = null;
private undoAvailable = false;
private undoTimer: Phaser.Time.TimerEvent | null = null;
```

### Undo Flow

```
1. Player drops animal (onDropRequested)
   → Save reference: this.lastDroppedAnimal = droppedAnimal
   → Set undoAvailable = true
   → Start timer: 800ms → undoAvailable = false
   → Show undo button (fade in)

2. Player taps Undo button (within 800ms, before collision)
   → Verify: undoAvailable && undosRemaining > 0 && lastDroppedAnimal.active
   → Destroy lastDroppedAnimal (spawner.destroyAnimal)
   → Restore nextTier preview to previous value
   → undosRemaining--
   → undoAvailable = false
   → Hide undo button
   → Re-enable input immediately (no drop cooldown)

3. Last animal collides with another body
   → Listen to 'collisionstart' on Matter.World
   → If colliding body === lastDroppedAnimal → undoAvailable = false, hide button

4. Timer expires (800ms)
   → undoAvailable = false, hide button
```

### Collision Lock

In GameScene.create(), wire collision listener:
```typescript
this.matter.world.on('collisionstart', (event: Phaser.Physics.Matter.Events.CollisionStartEvent) => {
  if (!this.undoAvailable || !this.lastDroppedAnimal) return;
  for (const pair of event.pairs) {
    const bodyA = pair.bodyA as any;
    const bodyB = pair.bodyB as any;
    const lastBody = this.lastDroppedAnimal.body;
    if (bodyA === lastBody || bodyB === lastBody) {
      // Last dropped animal touched something — can't undo anymore
      this.undoAvailable = false;
      this.hideUndoButton();
      break;
    }
  }
});
```

**Important:** Check against WALL bodies too. If animal hits wall, that's fine — undo should still be available. Only disable when colliding with another Animal (check label === 'animal').

Corrected:
```typescript
if ((bodyA === lastBody && bodyB.label === 'animal') ||
    (bodyB === lastBody && bodyA.label === 'animal')) {
  this.undoAvailable = false;
  this.hideUndoButton();
}
```

### AnimalSpawner Changes

Current AnimalSpawner.spawnAtDrop() at AnimalSpawner.ts:
- Creates animal, adds to `this.animals` set, emits `ANIMAL_DROPPED`
- Calls `this.rollNextTier()` for next preview

Need to add:
```typescript
private lastSpawned: Animal | null = null;
private previousNextTier: number = 0;

spawnAtDrop(x: number): Animal {
  this.previousNextTier = this.nextTier;  // save for undo restore
  // ... existing spawn logic
  this.lastSpawned = animal;
  return animal;
}

/** Undo last drop — destroy animal, restore next tier */
undoLastDrop(): boolean {
  if (!this.lastSpawned || !this.lastSpawned.active) return false;
  this.destroy(this.lastSpawned);
  this.nextTier = this.previousNextTier;
  this.lastSpawned = null;
  return true;
}
```

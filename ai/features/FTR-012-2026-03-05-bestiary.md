# Feature: [FTR-012] Bestiary — Collection Screen
**Status:** queued | **Priority:** P0 | **Date:** 2026-03-05

## Why
Visible Evolution Hierarchy — один из топовых engagement паттернов merge-игр (Score 3.00). Suika Game: 11 фруктов на лестнице — каждый новый создаёт milestone. Экран коллекции превращает случайный геймплей в цель ("открой всех"). Силуэты неоткрытых зверей — мощный "teasing" эффект, мотивирующий продолжать. ### ScoreManager Additions

```typescript
/** Mark a tier as discovered. Saves immediately. */
discoverTier(tier: number): boolean {
  const data = this.loadData();
  if (data.discoveredTiers.includes(tier)) return false;
  data.discoveredTiers.push(tier);
  data.discoveredTiers.sort((a, b) => a - b);
  this.saveData(data);
  return true; // newly discovered
}

getDiscoveredTiers(): number[] {
  return this.loadData().discoveredTiers;
}
```

**Step 4: Create `src/scenes/BestiaryScene.ts`**

```typescript
/**
 * Module: BestiaryScene
 * Role: Bestiary screen — displays all 8 animal tiers, silhouettes for undiscovered
 * Uses: config/GameConfig (ANIMALS, GAME, BRAND), game/ScoreManager
 * Used by: MenuScene (scene.start), main.ts (scene list)
 * Does NOT: Modify game state, manage physics
 */

import Phaser from 'phaser';
import { ANIMALS, GAME, BRAND } from '../config/GameConfig';
import { ScoreManager } from '../game/ScoreManager';

const TOTAL_TIERS = ANIMALS.length; // 8
const COLS = 4;
const ROWS = 2;
const CELL_W = 90;
const CELL_H = 110;
const SPRITE_SIZE = 64;
const GRID_GAP_X = 20;
const GRID_GAP_Y = 24;

export class BestiaryScene extends Phaser.Scene {
  constructor() {
    super('Bestiary');
  }

  create(): void {
    const { width, height } = this.scale;
    this.cameras.main.setBackgroundColor(BRAND.BG_CREAM);

    const scoreManager = new ScoreManager(this);
    const discovered = scoreManager.getDiscoveredTiers();
    const discoveredCount = discovered.length;

    // --- Title ---
    this.add.text(width / 2, 48, `Зверята: ${discoveredCount}/${TOTAL_TIERS}`, {
      fontSize: '28px',
      color: BRAND.TEXT_INK,
      fontFamily: BRAND.FONT_DISPLAY,
    }).setOrigin(0.5);

    // --- Grid ---
    // Total grid width: 4 cells * 90px + 3 gaps * 20px = 420px (fits in 480)
    const gridW = COLS * CELL_W + (COLS - 1) * GRID_GAP_X;
    const gridH = ROWS * CELL_H + (ROWS - 1) * GRID_GAP_Y;
    const gridStartX = (width - gridW) / 2 + CELL_W / 2;  // center of first cell
    const gridStartY = height * 0.28;

    for (let i = 0; i < TOTAL_TIERS; i++) {
      const col = i % COLS;
      const row = Math.floor(i / COLS);
      const cx = gridStartX + col * (CELL_W + GRID_GAP_X);
      const cy = gridStartY + row * (CELL_H + GRID_GAP_Y);

      const cfg = ANIMALS[i];
      const isDiscovered = discovered.includes(cfg.tier);

      if (isDiscovered) {
        // Sprite
        const sprite = this.add.image(cx, cy, cfg.key);
        const maxDim = Math.max(sprite.width, sprite.height);
        sprite.setScale(SPRITE_SIZE / maxDim);

        // Name label
        this.add.text(cx, cy + SPRITE_SIZE / 2 + 6, cfg.name, {
          fontSize: '13px',
          color: BRAND.TEXT_INK,
          fontFamily: BRAND.FONT_BODY,
        }).setOrigin(0.5, 0);
      } else {
        // Silhouette
        const sprite = this.add.image(cx, cy, cfg.key);
        const maxDim = Math.max(sprite.width, sprite.height);
        sprite.setScale(SPRITE_SIZE / maxDim);
        sprite.setTint(0x000000);
        sprite.setAlpha(0.25);

        // ??? label
        this.add.text(cx, cy + SPRITE_SIZE / 2 + 6, '???', {
          fontSize: '13px',
          color: BRAND.TEXT_SECONDARY,
          fontFamily: BRAND.FONT_BODY,
        }).setOrigin(0.5, 0);
      }
    }

    // --- Progress bar ---
    const barY = gridStartY + gridH + 48;
    const barW = 280;
    const barH = 16;
    const fillW = Math.round(barW * (discoveredCount / TOTAL_TIERS));

    // Background track
    const track = this.add.rectangle(width / 2, barY, barW, barH, 0xd6c6a9);
    track.setStrokeStyle(1, 0xb0a080);

    // Filled portion
    if (fillW > 0) {
      const fillRect = this.add.rectangle(
        width / 2 - barW / 2 + fillW / 2,
        barY,
        fillW,
        barH,
        0xd4a24c,
      );
      // Round-ish cap: slightly shrink height at edges — Phaser rectangles are square
      // Full rounded corners require Graphics; skip for simplicity at this LOC budget
      void fillRect; // used for side-effect (adding to scene)
    }

    // Progress text below bar
    const pct = Math.round((discoveredCount / TOTAL_TIERS) * 100);
    this.add.text(width / 2, barY + barH / 2 + 10, `${pct}%`, {
      fontSize: '16px',
      color: BRAND.TEXT_SECONDARY,
      fontFamily: BRAND.FONT_BODY,
    }).setOrigin(0.5, 0);

    // --- Back button ---
    const backY = barY + 64;
    const backBtn = this.add.rectangle(width / 2, backY, 160, 48, 0xede0c4);
    backBtn.setStrokeStyle(2, 0xb0a080);
    backBtn.setInteractive({ useHandCursor: true });

    const backText = this.add.text(width / 2, backY, 'Назад', {
      fontSize: '20px',
      color: BRAND.TEXT_INK,
      fontFamily: BRAND.FONT_BODY,
      fontStyle: 'bold',
    }).setOrigin(0.5);
    void backText;

    backBtn.on('pointerover', () => backBtn.setFillStyle(0xd6c6a9));
    backBtn.on('pointerout', () => backBtn.setFillStyle(0xede0c4));
    backBtn.on('pointerdown', () => backBtn.setScale(0.95));
    backBtn.on('pointerup', () => {
      backBtn.setScale(1);
      this.scene.start('Menu');
    });
  }
}
```

### Critical Notes for Coder

1. **NO atlas** — sprites are individual images. Use `this.add.image(x, y, cfg.key)` NOT `this.add.sprite(x, y, 'animals', cfg.key)`
2. **`void` suppression** — TS strict mode may warn about unused return values on text objects added for side effect. Use `void btnText;` pattern (already used in existing code implicitly — safe to add explicitly)
3. **ScoreManager migration** — existing users with saved data missing `discoveredTiers` will get `[1,2,3]` on first load via the patch in `loadData`. No manual migration step needed.
4. **checkAndSaveBest bug fix** — the fix in Task 1 (3a) preserves sound preference. This is a bonus fix, not breaking change.
5. **BestiaryScene LOC** — implementation above is ~100 LOC, well under 120 limit.
6. **`fillRect` side effect** — Phaser `this.add.rectangle()` adds to scene automatically. The `void fillRect;` suppresses TS "unused variable" lint warning.

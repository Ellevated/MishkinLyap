# Domain Dictionary

| Term | Meaning | NOT to confuse with |
|------|---------|---------------------|
| Казуалка | Простая игра, сессия 1-5 мин, low skill ceiling | Хардкорная игра (Dark Souls) |
| Drop Merge | Механика: объекты падают, одинаковые сливаются | Match-3 (ряды, не физика) |
| Suika Game | Оригинальная японская drop-merge игра с фруктами | Конкретный продукт, не жанр |
| MLP | Minimum Loveable Product — минимум чтобы не стыдно | MVP (может быть уродским) |
| Докрутка | Геймплейное/визуальное улучшение поверх базовой механики | Новая фича (масштабнее) |
| DLD | Фреймворк Олега для Claude Code | Не игровой движок |
| Phaser.js | HTML5 game framework с встроенной физикой | Unity, Godot (не веб-нативные) |
| Matter.js | Физический движок, встроен в Phaser | Arcade Physics (без вращения) |
| Яндекс Игры SDK | Обязательный JS SDK для монетизации и API | Самостоятельная рекламная сеть |
| Interstitial | Полноэкранная реклама между сессиями | Banner (маленький, постоянный) |
| Rewarded Video | Видео-реклама за бонус в игре | Принудительная реклама |
| Retention | Возврат игроков на следующий день/неделю | Просто DAU |
| Game Over | Конец сессии, триггер для рекламы | Конец игры навсегда |

# Problem: Показать ребёнку что код = деньги

---

## Persona: Камиль

**Who:** 10 лет, сын основателя. Осваивает Claude Code. Интересуется технологиями.
**Typical day:** Школа, потом свободное время — игры, YouTube, эксперименты с Claude Code.

**Pain:** Абстрактное понимание программирования. "Код — это что-то сложное и непонятное зачем".
- Frequency: Постоянное фоновое непонимание
- Cost: Мотивация к обучению — без видимого результата трудно продолжать

**Current solution:** Делает попытки в Claude Code, но нет конечного продукта с ощутимым результатом.
**Why doesn't work:** Нет связки "я написал код → оно работает → мне платят деньги".

## World Description

Поколение 10-летних растёт с AI-инструментами. Claude Code + фреймворки позволяют создавать рабочие продукты без глубокого знания языка. Но без конкретного примера "вот код, вот деньги" — это остаётся абстракцией.

Яндекс Игры — идеальная площадка: русскоязычная, бесплатная публикация, 45 млн MAU, встроенная монетизация через рекламу. Порог входа минимальный — HTML5-игра в ZIP-архиве.

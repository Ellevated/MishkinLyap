# Solution Sketch: Casual Game for Yandex Games

**One-liner:** Клон проверенной казуальной механики на Phaser.js для Яндекс Игр

**Warning: This is founder's RAW VISION. Not validated, not scoped, not formalized.**
**Board and Architect will refine this.**

---

## Founder's Vision

Берём из топа Яндекс Игр проверенную механику, клонируем за неделю на Phaser.js. Добавляем свой визуальный стиль и мелкие геймплейные докрутки (какие — станет ясно в процессе). Публикуем, монетизируем через рекламу SDK. Камиль видит баланс, понимает схему, потом делает свою игру.

**Лучший кандидат по результатам исследования:**

**Drop Merge (Suika Game / арбузная игра)**
- Бросаешь фрукты/объекты сверху
- Одинаковые объекты сливаются в более крупные
- Физика (Matter.js встроен в Phaser)
- 8-10 спрайтов — минимум ассетов
- Бесконечный геймплей, natural game over
- Идеальные точки для рекламы (после game over)

**Альтернативы:**
- Bubble Shooter — #1 по трафику, но больше кода
- Endless Runner — минимальный, но менее залипательный
- Idle/Кликер — очень просто, но может не пройти модерацию (10 мин геймплея)

---

## Key Scenario (as founder sees it)

1. Игрок открывает игру в каталоге Яндекс Игр
2. Тапает/кликает — объект падает с физикой
3. Одинаковые объекты сливаются → удовольствие
4. Game over → interstitial реклама → "ещё раз"
5. Rewarded video → бонус/продолжение
6. Retention: таблица рекордов, прогрессия

**"Wow!" moment:** Когда два объекта красиво сливаются с физикой и звуком.

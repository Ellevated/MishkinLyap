## Research (Exa) — Facts

### Платформа Яндекс Игры (2025)

| Метрика | Значение |
|---------|----------|
| MAU | 45-50 млн |
| Аудитория | 60% Россия, 40% мир |
| Демография | 58% женщины, 38% старше 55 |
| Опубликовано (2025) | 24,000 игр |
| Удалено (2025) | 29,000 игр |
| Формат | HTML5 (ZIP, max 100 MB) |
| Модерация | 3-5 рабочих дней |
| Минимум выплат | 3,000₽ (Россия) |

### Монетизация

| Тип | Описание |
|-----|----------|
| Interstitial | Полноэкранная реклама в паузах |
| Rewarded Video | Видео за бонус |
| Sticky Banner | Постоянный баннер |
| IAP | Внутриигровые покупки (90% дохода у топов) |

### Реальные доходы

| Уровень | Доход |
|---------|-------|
| Новичок, 1-я неделя | ~17₽/неделю |
| Простой клон | 500-2000₽/мес |
| Качественная казуалка | 50K-300K₽/мес |
| Топ-перфомер (с IAP) | $20K+/мес |

### Топ жанры

1. Bubble Shooter (#1 по трафику)
2. Merge / Слияние (#2, растёт)
3. Idle / Кликер (#3)
4. 2048 variants (drop-merge)
5. Слова / Кроссворды

### Факторы ранжирования

- DAU, retention, playtime, рейтинг
- ML-рекомендации (не pay-to-play)
- "Новинки" — 1 неделя бесплатного трафика
- Топ-5 программа: 20,000₽ на продвижение лучшим

## Why Now?

- AI позволяет одному человеку делать за неделю то, что раньше занимало месяц
- Камиль в возрасте, когда учится программировать — идеальный момент для наглядного примера
- Яндекс Игры растёт (+36% YoY) — платформа набирает

## Kill Scenarios

| Сценарий | Вероятность | Митигация |
|----------|-------------|-----------|
| 0 игроков → 0 денег | Средняя | Яндекс даёт трафик новинкам (1 неделя) |
| Проект затянется | Высокая | Жёсткий скоуп: 1 неделя, 1 механика |
| Отклонят на модерации | Низкая | Следуем требованиям SDK, 10+ мин геймплея |
| Рейтинг < 30 → удаление | Средняя | Качество > скорость, полировка UX |
| Не наберём 3000₽ на вывод | Высокая | Успех = видеть баланс растёт, не обязательно вывод |
